# 지갑 생성

Stable 지갑은 이더리움 표준 키 페어입니다. EVM 계정을 생성하는 모든 지갑 라이브러리는 수정 없이 Stable에서 작동합니다. 이 가이드는 두 가지 방법을 보여줍니다. 대부분의 애플리케이션에는 ethers.js를 사용하고, 에이전트 및 결제를 위한 턴키 자체 보관 계층을 원하는 통합에는 Tether의 [WDK (Wallet Development Kit)](https://github.com/tetherto/wdk)를 사용합니다.

:::note
등록, Stable별 계정 설정이 필요 없습니다. 지갑은 [테스트넷 수도꼭지](/ko/how-to/use-faucet) 또는 메인넷 전송을 통해 USDT0를 즉시 받을 수 있습니다.
:::

## 전제 조건

- Node.js 20 이상.

## 옵션 1: ethers.js

라이브러리를 설치하고 키 페어를 생성합니다.

```bash
npm install ethers
```

```typescript
// wallet.ts
import { ethers } from "ethers";

const provider = new ethers.JsonRpcProvider("https://rpc.testnet.stable.xyz");

/** 새로운 사용자를 위한 새 지갑을 생성합니다. */
export function createWallet() {
  const wallet = ethers.Wallet.createRandom(provider);
  return {
    wallet,
    address: wallet.address,
    seedPhrase: wallet.mnemonic!.phrase, // 백업을 위해 사용자에게 한 번 보여줍니다.
  };
}

/** 시드 구문에서 지갑을 복원합니다(기존 사용자). */
export function restoreWallet(seedPhrase: string) {
  const wallet = ethers.Wallet.fromPhrase(seedPhrase, provider);
  return { wallet, address: wallet.address };
}

if (import.meta.url === `file://${process.argv[1]}`) {
  const { address, seedPhrase } = createWallet();
  console.log("Address:    ", address);
  console.log("Seed phrase:", seedPhrase);
}
```

```bash
npx tsx wallet.ts
```

```text
Address:     0xAlice...1234
Seed phrase: liberty shoot ... (12 words)
```

:::warning
프로덕션 환경에서 시드 구문을 일반 텍스트로 기록하거나 저장하지 마십시오. 저장 시 암호화하거나 비밀 관리자를 사용하십시오. `ethers.Wallet.createRandom`은 호출당 한 번 구문을 반환합니다. 분실하면 자금을 복구할 수 없습니다.
:::

## 옵션 2: Tether WDK

WDK는 키 파생, 서명 및 트랜잭션 제출을 단일 인터페이스로 묶습니다. 일반적인 계정 흐름을 다시 구현하지 않고 자체 보관을 원할 때 올바른 선택이며, 에이전트 결제를 위해 [x402](/ko/how-to/build-pay-per-call)와 직접 통합됩니다.

```bash
npm install @tetherto/wdk @tetherto/wdk-wallet-evm
```

```typescript
// wallet-wdk.ts
import WDK from "@tetherto/wdk";
import WalletManagerEvm from "@tetherto/wdk-wallet-evm";

function initWdk(seedPhrase: string) {
  return new WDK(seedPhrase)
    .registerWallet("stable", WalletManagerEvm, {
      provider: "https://rpc.testnet.stable.xyz",
    });
}

/** 새로운 사용자를 위한 새 지갑을 생성합니다. */
export async function createWallet() {
  const seedPhrase = WDK.getRandomSeedPhrase();
  const wdk = initWdk(seedPhrase);
  const account = await wdk.getAccount("stable", 0);
  return {
    account,
    address: await account.getAddress(),
    seedPhrase, // 백업을 위해 사용자에게 한 번 보여줍니다.
  };
}

/** 시드 구문에서 지갑을 복원합니다(기존 사용자). */
export async function restoreWallet(seedPhrase: string) {
  const wdk = initWdk(seedPhrase);
  const account = await wdk.getAccount("stable", 0);
  return { account, address: await account.getAddress() };
}
```

```bash
npx tsx wallet-wdk.ts
```

```text
Address:     0xAlice...1234
Seed phrase: liberty shoot ... (12 words)
```

## 지갑에 자금 조달

지갑이 거래를 수행하려면 가스비를 위한 USDT0가 필요합니다. 테스트넷에서는 수도꼭지에서 요청하십시오.

```bash
open https://faucet.stable.xyz
```

주소를 붙여넣고 버튼을 선택하여 1 테스트넷 USDT0 (수천 건의 기본 전송에 충분함)를 받으십시오. 메인넷의 경우 지원되는 모든 거래소 또는 브릿지에서 USDT0를 보내십시오. [Stable로 USDT0 브릿징](/ko/explanation/usdt0-bridging)을 참조하십시오.

## 잔액 확인

네이티브 USDT0는 18자릿수를 사용합니다. 네이티브 잔액은 가스비가 지불되는 잔액입니다.

```typescript
// balance.ts
import { ethers } from "ethers";

const provider = new ethers.JsonRpcProvider("https://rpc.testnet.stable.xyz");
const balance = await provider.getBalance("0xYourAddress");
console.log("Balance:", ethers.formatEther(balance), "USDT0");
```

```bash
npx tsx balance.ts
```

```text
Balance: 1.0 USDT0
```
