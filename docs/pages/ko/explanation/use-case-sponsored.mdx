# 스폰서 및 가스 없는 경험

사용자 경험에서 가스를 완전히 제거하려는 앱은 첫 사용자가 두 번째 자산을 먼저 획득할 필요 없이 로그인하고 거래할 수 있도록 합니다.

## 문제점

사용자가 앱을 사용하기 전에 가스 토큰을 획득하도록 요구하는 것은 소비자 대상 제품의 전환을 방해하는 온보딩 절벽을 만듭니다. USDT(또는 아무것도 없는)만 가지고 나타난 신규 사용자는 거래를 제출할 수 없으며, 가스를 구매하기 위해 별도의 거래소로 보내는 것은 대부분의 사용자가 이탈하는 지점입니다.

## Stable이 문제를 해결하는 방법

- **가스 면제: 거버넌스 승인 면제는 사용자 대신 제로 가스 가격으로 실행되는 래퍼 트랜잭션을 제출하여 앱이 가스를 처음부터 끝까지 지불하고 사용자는 무료 작업을 보는 것과 같습니다.** [가스 면제](/ko/explanation/gas-waiver)를 참조하세요.
- **EIP-7702 세션 키를 사용하면 dApp이 범위가 지정된 시간 제한 권한을 보유할 수 있으므로, 사용자가 각 트랜잭션에 서명할 필요 없이 사용자 대신 트랜잭션을 제출할 수 있습니다.** [EIP-7702를 사용한 세션 키](/ko/how-to/session-keys)를 참조하세요.

## 다음 권장 사항

- [**가스 면제**](/ko/explanation/gas-waiver): 거버넌스 승인 면제가 제로 가스 가격으로 래퍼 트랜잭션을 제출하는 방법을 알아보세요.
- [**EIP-7702**](/ko/explanation/eip-7702): EOA가 dApp에 범위가 지정된 시간 제한 권한을 위임하는 방법을 이해하세요.
