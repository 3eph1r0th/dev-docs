# Stable의 계정

Stable의 계정은 [EIP-7702 위임](/ko/explanation/eip-7702)을 통해 스마트 계약 로직을 선택적으로 실행할 수 있는 표준 이더리움 EOA입니다. 사용자는 지갑, 일괄 결제, 반복 구독 및 세션 키에 걸쳐 하나의 주소와 하나의 개인 키를 유지합니다. 에이전트는 어떠한 관리 미들웨어 없이 동일한 계정 모델을 실행합니다.

## 구축할 수 있는 것

- 시드 문구를 사용하여 **지갑**을 만들고, 기본 USDT0 잔액 쿼리 및 서명된 트랜잭션을 실행합니다.
- **일괄 결제**: 위임된 EOA를 통해 여러 전송을 하나의 아토믹 트랜잭션으로 실행합니다.
- **지출 한도**: 위임 로직을 통해 EOA 자체에 대해 트랜잭션당 또는 일일 상한선을 적용합니다.
- **세션 키**: dApp에 범위가 지정되고 시간 제한이 있으며 예산 제한이 있는 키를 부여하여 사용자가 모든 작업을 다시 서명할 필요가 없도록 합니다.
- **에이전트 지갑**: 자체 보관 키로 AI 에이전트에 자금을 지원하고 x402 서비스에 자율적으로 지불하도록 합니다. 공급자 및 통합 패턴은 [에이전트 지갑](/ko/reference/agentic-wallets)을 참조하세요.

## Stable이 다른 점

- **모든 것에 하나의 주소.** 스마트 계약 기능을 잠금 해제하기 위한 계정 마이그레이션이 없습니다. EIP-7702는 기존 EOA *에* 코드를 위임합니다.
- **USDT0 전용 가스.** 사용자는 별도의 기본 토큰이 필요하지 않습니다. 새 계정은 USDT0으로 자금을 조달하고 즉시 거래할 수 있습니다.
- **다기능 위임 패턴.** 단일 위임자는 일괄 처리, 지출 한도, 세션 키 및 구독을 결합하여 하나의 위임으로 제공하는 모든 기능을 커버할 수 있습니다.

## 여기에서 시작

- [**지갑 만들기**](/ko/how-to/create-wallet): ethers.js 또는 Tether WDK로 지갑을 생성하거나 복원합니다.
- [**EIP-7702로 위임하기**](/ko/how-to/account-abstraction): 기존 EOA에서 여러 결제를 하나의 트랜잭션으로 일괄 처리합니다.
- [**세션 키**](/ko/how-to/session-keys): 범위가 지정되고 만료되는 키를 부여하여 사용자가 모든 작업을 다시 서명할 필요가 없도록 합니다.
- [**Stable SDK**](/ko/explanation/sdk-overview): 유형화된 클라이언트를 사용하여 모든 계정에서 트랜잭션을 서명하고 보냅니다.
