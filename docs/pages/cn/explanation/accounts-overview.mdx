# Stable 上的账户

Stable 上的账户是一个标准的以太坊 EOA，可以选择通过 [EIP-7702 委托](/cn/explanation/eip-7702) 执行智能合约逻辑。用户在钱包、批量支付、定期订阅和会话密钥中共享一个地址和一个私钥。代理运行相同的账户模型，无需任何托管中间件。

## 您可以构建什么

- **钱包**：从助记词生成，具有原生 USDT0 余额查询和签名交易功能。
- **批量支付**：通过委托的 EOA 在一个原子交易中执行多次转账。
- **消费限额**：通过委托逻辑在 EOA 本身强制执行每笔交易或每日限额。
- **会话密钥**：授予 dApp 范围、有时限、有预算的密钥，以便用户无需重新签署每个操作。
- **代理钱包**：用自托管密钥为 AI 代理提供资金，并让它自主支付 x402 服务费用。请参阅 [代理钱包](/cn/reference/agentic-wallets) 了解提供商和集成模式。

## Stable 的不同之处

- **一个地址处理所有事务。** 无需账户迁移即可解锁智能合约功能。EIP-7702 将代码委托到现有的 EOA 上。
- **仅限 USDT0 作为 Gas 费。** 用户不需要单独的原生代币。新账户用 USDT0 充值后即可立即进行交易。
- **多功能委托模式。** 单一委托可以组合批量、消费限额、会话密钥和订阅，因此一次委托即可涵盖您发布的所有功能。
